# 4. Non-Functional Requirements

## Таблиця NFR

| # | Категорія | Вимога | Критерій прийняття |
|---|-----------|--------|--------------------|
| NFR-01 | Продуктивність | Сторінка каталогу завантажується не довше 2 с при 100 одночасних користувачах | Навантажувальний тест (k6 / JMeter): 95-й перцентиль ≤ 2 с |
| NFR-02 | Продуктивність | API-відповідь на пошук та фільтрацію ≤ 500 мс | Середній час відповіді ≤ 500 мс (Postman / Swagger) |
| NFR-03 | Зручність (UX) | Новий користувач реєструється й публікує оголошення менш ніж за 5 хвилин | Юзабіліті-тест з 3 користувачами без підказок |
| NFR-04 | Зручність (UX) | Усі повідомлення про помилки відображаються зрозумілою мовою, без технічних деталей | Ручне тестування: перевірка текстів помилок у всіх сценаріях |
| NFR-05 | Адаптивність | Інтерфейс коректно працює від 375 px до 1920 px | Тестування в DevTools + Playwright на трьох розмірах екрану |
| NFR-06 | Адаптивність | Підтримка актуальних версій Chrome, Firefox, Edge | Крос-браузерне тестування (остання стабільна версія кожного браузера) |
| NFR-07 | Безпека | Паролі зберігаються лише у хешованому вигляді (ASP.NET Identity / PBKDF2), передача даних — лише через HTTPS | Аудит БД: відсутність відкритих паролів; OWASP ZAP сканування |
| NFR-08 | Безпека | Усі захищені ендпоінти вимагають валідний JWT-токен | Запит без токена або з простроченим токеном повертає `401 Unauthorized` |
| NFR-09 | Надійність | Сервіс автоматично застосовує міграції БД при запуску | При старті контейнера `MigrateAsync()` виконується без помилок |
| NFR-10 | Сумісність | Система підтримує Docker-розгортання на Linux / Windows / macOS | `docker-compose up` запускає API та PostgreSQL без додаткової конфігурації |

## Довідник категорій

| Категорія | Приклади |
|-----------|----------|
| Продуктивність | Час відповіді, пропускна здатність, ємність навантаження |
| Безпека | Автентифікація, шифрування даних, валідація введення |
| Сумісність | Браузери, ОС, розміри екрану |
| Надійність | Uptime, відновлення після збоїв, резервне копіювання |
| Зручність (UX) | Доступність, онбординг, повідомлення про помилки |
| Адаптивність | Мобільний макет, розміри екрану |
