# 1. Vision

## 1.1 Проблема

Люди, які хочуть продати або купити вживану техніку, змушені користуватися розрізненими платформами без зручного пошуку, фільтрації та комунікації між продавцем і покупцем. Відсутність спеціалізованого майданчика для б/у техніки ускладнює пошук потрібного товару та знижує довіру між учасниками угоди.

---

## 1.2 Рішення

**TechSurvivor** — це маркетплейс оголошень для купівлі та продажу вживаної техніки. Система дозволяє реєструватись і публікувати оголошення з фото, описом, ціною, категорією та містом. Покупці можуть переглядати каталог, шукати товари за фільтрами та зв'язуватись із продавцями через вбудований чат. Передбачена адмін-панель для модерації контенту. У майбутньому планується розширення з оплатою, доставкою та системою рекомендацій.

---

## 1.3 Scope

| ✅ В межах проєкту | ❌ Поза межами проєкту |
|-------------------|----------------------|
| Реєстрація та авторизація користувачів (JWT) | Мобільний додаток |
| Публікація оголошень (фото, опис, ціна, категорія, стан, місто) | Реальна інтеграція платіжних систем |
| Каталог товарів та перегляд оголошення | Push-сповіщення |
| Пошук і фільтрація (категорія, ціна, стан, місто) | Відео-дзвінки |
| Чат між покупцем і продавцем | Система рекомендацій (ШІ) |
| Оформлення замовлень з оплатою та доставкою | Інтеграція з Укрпоштою / Новою Поштою |
| Відгуки та рейтинг продавців | SEO-оптимізація |
| Обрані оголошення | Соціальна авторизація (OAuth) |
| Просування оголошень (підняття в топ) | Мультивалютні платежі |
| Адміністративна панель (керування оголошеннями) | ШІ-асистент для підбору товару |
| Банерна реклама | — |
